# CPP-2D-Arrays


This is a C++ implementation of 2d arrays

## Description
- It shows the list of numbers that are higher or less than 50 respectively, while aksing the user for the number of rows and columns. This is made for understanding the syntax changes on how to handle the same code in different languages
- 

## Features
- Shows numbers higheer than 50
- Shows numbers lower than 50


## Technologies
- Language / Framework: C++


## How to run (local)
1. Clone: `git clone https://github.com/Sxoony/CPP-2D-Arrays.git`
2. Navigate: `cd CPP-2D-Arrays`
3. Setup
- Open in Visual Studio (C#)
4. Run
